# Faizan-e-Quran Academy - Website Replica

This is an exact UI replica of the [Faizan-e-Quran Academy website](https://www.faizanequran.co/), built with HTML, CSS, and JavaScript.

## Overview

Faizan-e-Quran Academy is an online Islamic education platform that offers comprehensive Quran learning courses, Islamic studies, and religious education. This replica captures the original website's design, layout, and functionality.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Islamic Theme**: Green color scheme with Islamic-inspired design elements
- **Course Management**: Display of various Islamic courses with details
- **Interactive Elements**: Smooth scrolling, form handling, and hover effects
- **Contact System**: Complete contact form with validation
- **Newsletter Signup**: Email subscription functionality
- **Social Media Integration**: Links to social platforms
- **Mobile Navigation**: Hamburger menu for mobile devices

## Customization

### Adding New Courses
1. Add course card HTML in the courses section
2. Style using existing `.course-card` class
3. Add JavaScript interactions if needed

### Modifying Colors
Update CSS variables in `styles.css`:
```css
:root {
    --primary-green: #2c5530;
    --secondary-green: #4a7c59;
    --accent-gold: #ffd700;
}
```

### Adding New Sections
1. Create HTML structure
2. Add corresponding CSS styles
3. Include navigation links if needed
4. Add JavaScript interactions
